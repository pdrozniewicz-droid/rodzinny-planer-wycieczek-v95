Rodzinny Planer Wycieczek — V9.5

V9.5: komunikacja przez backend, cache odpowiedzi, mniejsze zapytania, diagnostyka źródeł i jawny status API. Uruchom przez serwer aplikacji; sam plik HTML nie zapewnia backendu. Wikipedia nie jest używana jako źródło ani wyświetlana jako odnośnik.

Jeśli aplikacja jest wdrożona razem z backendem, zostaw puste. Jeśli frontend i backend są osobno, wpisz adres backendu HTTPS. Otwieranie pliku HTML bez serwera nie uruchamia backendu.
